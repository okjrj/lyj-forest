# 숲 속의 요정

이윤진 — 손짓으로 여는 AI 세계 · **v1.0.2**

**[🌲 forest.html 실행하기](https://okjrj.github.io/lyj-forest/forest.html)**

링크를 열고 마우스를 움직이면 숲과 요정이 나타납니다. 웹캠을 사용하려면 화면에서 **웹캠 켜기**를 누르고 카메라 사용을 허용하세요.

PC에서는 `forest.html`을 Chrome으로 열어 실행할 수 있습니다. 자세한 사용법은 [사용방법.txt](사용방법.txt)를 참고하세요.

## v1 기능

- 여러 층의 눈 덮인 픽셀 숲과 눈사람·트리 요정
- 마우스를 따라오는 캐릭터와 원형 손전등 조명
- 가까운 선물을 클릭하거나 웹캠 앞에서 입을 벌려 먹기
- 선물을 먹을 때 귀여운 와그작 효과음, 효과음 켜기·끄기
- 소등 후 다시 움직이면 선물 재생성
- 웹캠 눈·입 합성, 이미지 교체, 일시정지, 전체 화면

웹캠 영상은 PC 안에서 처리합니다. 얼굴 추적 모델을 처음 불러올 때 인터넷이 필요합니다.

## 확인

`node tests/forest-gameplay.cjs`로 데스크톱·모바일 게임 동작을 검사합니다.
Chromium 실행 파일을 찾지 못하면 `CHROME_PATH` 환경 변수에 Chrome 경로를 지정하세요.
픽셀 글꼴은 `assets/fonts`에 포함되어 있으며 라이선스도 같은 폴더에 있습니다.
